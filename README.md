# Pandas Learning Notes

## About This Repository

This repository contains my learning notes and practical examples of Pandas, a Python library used for data manipulation and analysis.

I created these Jupyter Notebooks while learning Pandas and practicing its important concepts using different datasets.

## Topics Covered

The following topics are covered in this repository:

1. **Pandas Series** — Creating Series, accessing elements, and understanding Series attributes.
2. **Pandas DataFrame** — Creating DataFrames, accessing data, indexing, and selecting rows and columns.
3. **Important DataFrame Methods** — Exploring useful methods for inspecting and manipulating data.
4. **GroupBy** — Grouping data and performing aggregate operations.
5. **Merging, Joining, and Concatenation** — Combining multiple DataFrames.
6. **MultiIndex** — Working with hierarchical indexing in Series and DataFrames.
7. **Pivot Tables and DateTime** — Summarizing data and working with dates and times.
